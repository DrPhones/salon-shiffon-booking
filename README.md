# صفحة حجز صالون شيفون

- `index.html` — التصميم الحالي (الاتجاه الليلي): نفس الكتالوج ونفس منطق رسوم الحجز ورسالة واتساب، بواجهة جوال أولًا.
- `legacy/index.html` — التصميم السابق كما كان قبل إعادة التصميم، محفوظ دون تعديل ويعمل مستقلًا (افتحه مباشرة أو عبر `/legacy/`).

## الاسترجاع إلى التصميم السابق

```bash
git mv index.html night/index.html   # اختياري: الاحتفاظ بالتصميم الليلي
git mv legacy/index.html index.html
git commit -m "Revert to legacy booking design"
```

## قواعد العمل الثابتة في الصفحتين

- رسوم الحجز 20 ريالًا تُضاف فقط للخدمات المعلَّمة `bookable: true` في الكتالوج (التساريح، وأربع خدمات مكياج). قص الشعر والاستشوار وبقية الخدمات بلا رسوم حجز وتُراجَع من الموظفة.
- لكل خدمة حقل «الموظفة المفضلة» اختياري، مع إبلاغ العميلة أن وجود الموظفة يخضع للتوفر وأن المعتمد في الحجز هو الوقت.
- الطلب يُرسل نصًا عبر واتساب إلى رقم الصالون بعد التحقق من الاسم والجوال والتاريخ وبداية الساعة (10ص–9م).
